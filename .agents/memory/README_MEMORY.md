# Sistema Cognitivo del Proyecto (Memory System)

Este directorio conforma el cerebro a largo plazo del Agente. Al copiar esta carpeta `.agents/memory/` a otro proyecto, te estás llevando la "personalidad", "experiencia" y "conocimientos" adquiridos por la IA.

### Clasificación Cognitiva:
1. **Memoria Semántica (`SEMANTIC.md`):** El "Qué". Hechos estáticos, preferencias de lenguajes, reglas de negocio inmutables.
2. **Memoria Episódica (`EPISODIC.md`):** El "Cuándo". Bitácora de decisiones, hitos logrados y contexto histórico del proyecto.
3. **Memoria Procedimental (`PROCEDURAL.md`):** El "Cómo". Patrones de razonamiento exitosos y flujos de resolución de bugs específicos del proyecto.

> *Nota: La **Memoria a Corto Plazo** no requiere archivo físico, ya que está representada por la ventana de contexto de la sesión actual de chat.*
